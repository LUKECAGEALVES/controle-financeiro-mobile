# Publicar a v0.7.2 no GitHub Pages

1. Abra o repositório `controle-financeiro-mobile`.
2. Use **Add file → Upload files**.
3. Envie o conteúdo desta pasta, mantendo `index.html`, `app.js`, `parity-core.js`, `parity-pages.js`, `styles.css`, `manifest.json`, `sw.js` e `assets/` na raiz.
4. Faça commit direto na branch `main`.
5. Aguarde o GitHub Pages concluir o deploy.
6. Abra o site e confirme no cabeçalho **Mobile v0.7.2**.

Se o navegador mantiver versão antiga, feche/reabra o PWA ou limpe apenas o cache do site.
