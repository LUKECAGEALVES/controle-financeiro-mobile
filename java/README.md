# Motor Java — FGTS x Reinvestimento

`InvestmentFgtsCalculator.java` replica o motor financeiro da nova calculadora.
Ele não é chamado pela interface PySide6; foi incluído como implementação Java
independente e base para uma futura versão Android nativa.

Compilar e testar:

```bash
javac InvestmentFgtsCalculator.java
java InvestmentFgtsCalculator
```
